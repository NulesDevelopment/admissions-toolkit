# Інструкція користувача

Інструмент приймальної комісії НУБіП: **особисті справи** (форми Н-2.01 / Н-1.03.1) і **статистика** вступників. Усі дані з ЄДЕБО обробляються **локально в браузері** і не надсилаються на сервер.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте адресу з терміналу (зазвичай `http://localhost:5173`).

| Сторінка | URL | Для чого |
| -------- | --- | -------- |
| Особові справи | `/sprava` | Форми особової справи, друк, DOCX, фото |
| Статистика | `/statystyka` | Підсумки, графіки, категорії, експорт CSV |

---

## Особові справи (`/sprava`)

### Підготовка

1. У **Налаштуваннях** вкажіть термін навчання, рік вступу, секретаря, назву ЗВО.
2. **Дати наказів…** — таблиця «дата → номери наказів» (через кому). Зберігається в `localStorage` браузера.
3. Вивантажте з ЄДЕБО файл заявок (**`.xlsx` / `.xls` / `.csv`**).

### Завантаження файлу

- Залишаються лише рядки зі статусом **«До наказу»**.
- Файл кешується в IndexedDB **на 12 годин** (після F5 відновиться).
- Якщо 0 рядків «До наказу» — у повідомленні будуть інші статуси з файлу (перевірте, чи той експорт).

### Фільтри

1. Обов’язково оберіть **спеціальність** (без неї список порожній).
2. Факультет звужує список спеціальностей; спеціальність — список форм навчання.
3. Можна шукати за ПІБ і фільтрувати бюджет/контракт (бюджет = наказ з номером **1255**).

### Форми та друк

- **Переглянути** — Н-2.01 + Н-1.03.1; текст редагований кліком.
- **Фото** (рамка на Н-1.03.1): клік / ⬆ — файл; перетягування; колесо або `+` `−`; `⤢` — вписати; `✕` — видалити. Фото прив’язане до № справи.
- **DOCX** — Word-файл для одного вступника.
- **Згенерувати форми** — пакет усіх відфільтрованих у повноекранному режимі → **Друкувати**.

### Після друку від руки

- Підпис секретаря.
- Паспорт до **01.08.2022** — серія/номер/дата/орган (у формі порожні).
- У таблиці документів — аркуші, дати вилучення/повернення.

### Новий файл

Кнопка **Новий файл** очищає список, фото і кеш файлу. Налаштування й дати наказів лишаються.

## Статистика (`/statystyka`)

1. Завантажте CSV з ЄДЕБО.
2. За потреби оберіть кодування (Auto / UTF-8 / Windows-1251) — зміна **перечитує** вже збережений файл.
3. Оберіть факультет.
4. Редагуйте пороги балів (з невеликою затримкою, щоб не гальмувати).
5. Клік по числах відкриває деталі; є графіки, категорії, дублікати.
6. **Експорт** CSV по секціях; **Друк таблиці** — лише таблиця підсумків; **Друк PDF** — увесь звіт.
7. Кеш CSV у IndexedDB на **12 годин**; **Скинути збережене** очищає диск і пам’ять.

---

## Приватність

У файлах — персональні дані. Не діліться скрінами з ПІБ. Кеш живе лише на вашому комп’ютері й зникає після TTL або очищення.
